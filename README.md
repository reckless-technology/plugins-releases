# Reckless Technology plugins

The downloads of the Reckless Technology plugins: twenty-one audio plugins, free for any use - twenty effects and a
Pedalboard that chains them - each a VST3, an Audio Unit on macOS and a standalone app.

| | | |
|---|---|---|
| macOS 13.3 (Ventura) or later, Apple silicon or Intel | [reckless-plugins-macos.pkg](https://github.com/reckless-technology/plugins-releases/releases/latest/download/reckless-plugins-macos.pkg) | signed and notarized installer |
| Windows 10 or 11, 64-bit | [reckless-plugins-win64-setup.exe](https://github.com/reckless-technology/plugins-releases/releases/latest/download/reckless-plugins-win64-setup.exe) | signed installer |
| Linux x64: Debian, Ubuntu, Mint | [reckless-plugins-linux-amd64.deb](https://github.com/reckless-technology/plugins-releases/releases/latest/download/reckless-plugins-linux-amd64.deb) | `sudo apt install ./reckless-plugins-linux-amd64.deb` |
| Linux x64, any distribution with glibc 2.38 | [reckless-plugins-linux-x64.zip](https://github.com/reckless-technology/plugins-releases/releases/latest/download/reckless-plugins-linux-x64.zip) | the VST3s and apps to copy by hand |

Every release is listed under [Releases](https://github.com/reckless-technology/plugins-releases/releases) with its notes, the
user guide and `SHA256SUMS`, each file's checksum. The download page, the user guide and the news are at
[recklesstechnology.com](https://recklesstechnology.com/plugins/download/).

This repository holds the downloads alone. The plugins are free to use under the end-user licence each installer shows
(also at [recklesstechnology.com/legal/eula](https://recklesstechnology.com/legal/eula/)); they are not open source.
Questions, bugs and ideas: hello@recklesstechnology.com.
